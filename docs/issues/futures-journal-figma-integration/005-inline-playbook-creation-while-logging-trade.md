## What to build

Add inline Playbook creation to the add-trade flow. When a user needs a new Playbook while logging a Trade, they can create it from the trade form and the newly created Playbook is automatically selected for that Trade.

## Acceptance criteria

- [ ] Add-trade flow exposes a New Playbook action near the Playbook selector.
- [ ] Inline Playbook creation collects name, description, color, and rules.
- [ ] Newly created Playbook is immediately selected for the current Trade.
- [ ] Flow works when the user has no existing Playbooks.
- [ ] Visual test: capture a screenshot of inline Playbook creation from the trade modal.
