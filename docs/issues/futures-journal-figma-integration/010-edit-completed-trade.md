## What to build

Let users edit an existing completed Trade and its Journal Entry from the drawer or row action. Trade idea and confluences remain stored once on the Journal Entry.

## Acceptance criteria

- [ ] Users can open edit state from a selected Trade.
- [ ] Users can update Trade facts and Journal Entry fields.
- [ ] Derived Realized P&L and Outcome Status update after edits.
- [ ] Ownership checks prevent editing another user's Trade.
- [ ] Visual test: capture a screenshot of edit modal or edit state launched from a selected Trade.
