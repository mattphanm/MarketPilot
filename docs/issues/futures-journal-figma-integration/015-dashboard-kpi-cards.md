## What to build

Build the Figma-style Dashboard KPI section using completed futures Trade outcomes. Metrics should be supported by the journal model and should not include live portfolio concepts.

## Acceptance criteria

- [ ] Dashboard shows net P&L, win rate, total trades, average R, average win, average loss, and profit factor.
- [ ] Metrics are derived from completed Trades only.
- [ ] Dashboard does not show portfolio value, cash balance, open positions, unrealized gains, or sector allocation.
- [ ] Empty states are clear when no Trades exist.
- [ ] Visual test: capture a screenshot of the Dashboard KPI grid populated from real Trades.
