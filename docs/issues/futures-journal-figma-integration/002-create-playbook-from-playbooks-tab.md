## What to build

Let an authenticated user create a Playbook from the Playbooks tab. A Playbook stores its definition: name, description, color, and individual rules. The UI should follow the Figma Playbooks layout with a list/card area and a selected-detail panel.

## Acceptance criteria

- [ ] Users can create a Playbook with name, description, color, and individual rules.
- [ ] Playbooks are scoped to the authenticated user.
- [ ] Playbook creation validates required fields and rule shape.
- [ ] Created Playbooks are visible in the Playbooks tab without a page reload.
- [ ] Visual test: capture a screenshot of the Playbooks tab with one created Playbook and its selected-detail panel.
