## What to build

Build the first visible Figma-style app shell for MarketPilot. The authenticated app should show the Sidebar and TopBar layout with the futures journal navigation: Dashboard, Trade Log, Journal, Playbooks, Analytics, and Settings. Each tab may initially render a clear empty state, but the old Portfolio, Watchlist, Open Monitor, and Calendar navigation must no longer be present.

## Acceptance criteria

- [ ] Authenticated users see a Figma-style shell with Sidebar and TopBar.
- [ ] Navigation includes Dashboard, Trade Log, Journal, Playbooks, Analytics, and Settings.
- [ ] Removed views do not appear in the primary navigation.
- [ ] Each tab is reachable and renders an empty state or placeholder surface.
- [ ] Visual test: capture a desktop screenshot showing the shell and all navigation items.

## Blocked by

None - can start immediately.
