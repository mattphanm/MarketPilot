## What to build

Let users delete a completed Trade from the Trade Log flow. Deleting a Trade should clean up or cascade its associated Journal Entry and refresh the visible table/drawer state.

## Acceptance criteria

- [ ] Users can delete a Trade they own.
- [ ] Associated Journal Entry is cleaned up or cascaded.
- [ ] Users cannot delete another user's Trade.
- [ ] Trade Log and drawer state update after deletion.
- [ ] Visual test: capture a screenshot of confirmation UI or post-delete table state.
