## What to build

Add edit and delete flows for existing Playbooks. Users should be able to update a Playbook's definition fields and remove a Playbook when it is safe to do so, with ownership checks enforced.

## Acceptance criteria

- [ ] Users can edit Playbook name, description, color, and rules.
- [ ] Users can delete Playbooks they own when deletion rules allow it.
- [ ] Users cannot edit or delete another user's Playbooks.
- [ ] Validation errors are visible in the UI.
- [ ] Visual test: capture a screenshot of the edit state or modal with existing Playbook rules populated.
