## What to build

Simplify the MarketPilot top bar so it shows the page title/subtitle, the signed-in trader affordances that remain in scope, and the shared Entry-Time Range presets: ALL, 30D, 90D, and YTD. Remove placeholder controls that imply product workflows that do not exist: Current range, global Search, Sync, and notifications. The remaining presets must be visually clear, responsive on narrow screens, and expose selected state to assistive technology.

## Acceptance criteria

- [ ] The top bar no longer exposes Current range, global Search/Cmd K, Sync, or notification controls.
- [ ] The top bar still exposes ALL, 30D, 90D, and YTD Entry-Time Range presets using the existing range values.
- [ ] The selected Entry-Time Range is visually distinct and exposes selected state for keyboard and assistive-technology users.
- [ ] The presets remain usable on narrow screens without layout overlap; horizontal overflow is acceptable for the preset group.
- [ ] No import, broker sync, export, notification, global search, or command-palette workflow is introduced.
