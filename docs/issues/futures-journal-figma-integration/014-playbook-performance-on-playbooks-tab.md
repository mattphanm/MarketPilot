## What to build

Show derived Playbook performance on the Playbooks tab. Metrics are calculated from completed Trades assigned to each Playbook and are not stored as independent Playbook fields.

## Acceptance criteria

- [ ] Playbooks tab shows win rate, average return/P&L, average R, total trades, best Trade, and worst Trade.
- [ ] Metrics update when assigned Trades are created or edited.
- [ ] Empty Playbooks show sensible empty performance states.
- [ ] Metrics only include Trades owned by the authenticated user.
- [ ] Visual test: capture a screenshot of Playbooks tab showing real derived stats from logged Trades.
