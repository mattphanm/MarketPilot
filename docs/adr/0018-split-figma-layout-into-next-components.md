# Split the Figma layout into focused Next.js components

MarketPilot will use the Figma export as the target layout and interaction model, but will not copy the Vite app wholesale. The integration should replace the current large trade journal component with focused Next.js components such as Sidebar, TopBar, DashboardView, TradeLogView, JournalView, PlaybooksView, SettingsView, and modal/detail components wired to the real futures journal data model.
